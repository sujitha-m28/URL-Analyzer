# URL Analyzer Project

## Tech Stack
Frontend: Angular  
Backend: Spring Boot  

## Features
- Analyze any URL
- Get status code (200, 404, etc.)
- Response time check
- Simple defect detection

## How to Run

### Backend
cd backend  
mvn spring-boot:run  

Runs on:
http://localhost:8080

---

### Frontend
cd frontend  
npm install  
ng serve  

Runs on:
http://localhost:4200

## API
POST /api/analyze
